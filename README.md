# Teacher Records Kit

> 一個**交給 AI 就能裝好**的「導師專用學生紀錄系統」。
> 每位導師都能擁有一個**只有自己看得到**的網頁儀表板：每月記錄、檢視、編輯每位學生的觀察，
> 並（選用）一鍵把某則改寫成家長語氣寄給家長。

這是一個**空殼模板**——不含任何特定班級或學生資料。你把它交給一個 AI 代理（如 Claude Code、Cursor、或任何能讀 `AGENTS.md` 的 AI），對它說：

> 「讀 AGENTS.md，幫我把這套裝起來。」

AI 會**一步一步問你需要的資料**（你的 Email、Firebase 專案、學生名單來源…），缺什麼就引導你補，最後幫你部署成可用的系統。

---

## 它能做什麼

- 🔒 **只有你看得到**：資料存在 Google Firestore，靠伺服器端規則鎖定「只有你的 Google 帳號」可讀寫。別人（含家長、同事、任何拿到網址的人）都看不到。
- 📋 **全班一覽**：列出所有學生，標出「本月已記 / 未記」，一眼看出誰還沒做。
- ✍️ **線上記錄與編輯**：點進學生即可新增 / 編輯觀察，最新的排在前面。
- 🏠 **兩種上線方式**：① 獨立網站（GitHub Pages）② **嵌進你現有的網站**（隱形、只有你登入看得到，見 `embed/`）。
- ✉️ **（選用）寄家長信**：把某則觀察改寫成家長語氣，確認後寄給家長（Gmail）。
- ⏰ **（選用）每月提醒**：自動提醒你本月哪些學生還沒記。

## 怎麼開始

1. 把這個 repo 交給你的 AI 代理。
2. 說：「讀 `AGENTS.md`，幫我設定。」
3. 照 AI 的提問一關一關回答即可。

> 不想用 AI？看 `INSTALL.md` 的手動步驟。

## 隱私

- 你的真實資料（學生紀錄、名冊、家長 email）全部放在 `data/`，並由 `.gitignore` 擋住，**永不進 git**。
- 設定檔 `config.yaml`、Firebase 金鑰、SMTP 密碼也都 gitignored。
- 這個公開 repo 本身只含**範本與程式碼**，零個資。
