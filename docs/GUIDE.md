# 給老師的入門：從「我沒用過 AI」開始

這份文件假設你**完全沒有碰過 AI 代理、沒有開過終端機、不知道 GitHub 是什麼**。
沒關係，這些東西比想像中簡單，而且大部分事情是 AI 幫你做，不是你做。

全部走完大約 30 到 60 分鐘，其中大半是等程式安裝。

---

## 0. 先弄懂三個名詞（只有三個）

**AI 代理**
你用過 ChatGPT 那種「打字問它、它回你」的 AI 吧？AI 代理是它的另一種樣子：
除了跟你講話，它還**能真的動你電腦上的檔案、真的執行程式**。
所以你可以對它說「幫我把這套系統裝起來」，它會真的去裝，而不是告訴你「你可以這樣做……」。

**終端機（Terminal）**
你電腦上一個黑底白字的視窗，用打字下指令。
你**幾乎不用自己打任何指令**——它只是 AI 代理住的地方。你打開它、把 AI 叫起來，之後就用中文跟 AI 講話。

**Repo（程式資料夾）**
就是一個資料夾，裡面裝著這套系統的程式。你會把它下載到你的電腦上。

---

## 1. 裝 Claude Code

Claude Code 就是我們要用的 AI 代理，它跑在終端機裡。

1. 先確認你有 Claude 帳號。沒有的話到 https://claude.ai 註冊一個。
2. 打開安裝說明：**https://docs.claude.com/en/docs/claude-code**
   照那一頁「Install / 安裝」的步驟做（它會給你一行安裝指令）。
3. 安裝需要用到終端機——**怎麼開終端機看下一節**，開好之後把那一行指令貼進去、按 Enter。

裝好之後，在終端機打 `claude` 按 Enter，會看到 Claude Code 啟動、要你登入。
登入用的就是你 https://claude.ai 那個帳號。

> **看不懂安裝頁上的英文？** 沒關係——把那一頁的網址貼給 https://claude.ai 上的 Claude，
> 說「我用 Mac，請你用中文一步一步告訴我怎麼裝 Claude Code」。它會帶你做。

---

## 2. 怎麼開終端機（macOS）

三種方法，挑一個：

- **最快**：按 `⌘ + 空白鍵`（Spotlight 搜尋）→ 打 `terminal` → 按 Enter。
- 或：打開「應用程式」→「工具程式」→「終端機」。
- 或：Launchpad → 搜尋「終端機」。

打開之後你會看到一個視窗，裡面有一行字然後一個游標在閃。**那就對了。**
你要做的只有兩件事：**貼上文字**（`⌘ + V`）跟**按 Enter**。

> 覺得字太小 → 選單「終端機」→「設定」→ 調字級。眼睛比較舒服，你等一下會盯著它一陣子。

---

## 3. 把這套系統下載到你的電腦

作者會寄一封 GitHub 邀請信給你（寄件人是 GitHub，主旨大概是
「… invited you to collaborate on …」）。

1. **開信，按信裡的綠色按鈕**（`View invitation` 或 `Accept invitation`）。
2. 網頁會打開 GitHub。沒有 GitHub 帳號的話它會請你先註冊一個（免費，用你的信箱就好）。
3. 按 **`Accept invitation`**。
4. 接受之後你會進到這個 repo 的頁面。找到右上方那顆綠色的 **`Code`** 按鈕，點它。
5. 下拉選單最下面有 **`Download ZIP`**，點下去。
6. 下載好的 zip 檔在你的「下載項目」資料夾。**點兩下解開它**，
   然後把解開的那個資料夾**拖到桌面**（放哪裡都行，但桌面最好找）。

> **懂一點電腦、想用 git 的話**：`Code` 按鈕裡有一段 `git clone https://github.com/...` 的網址，
> 在終端機打 `git clone <那段網址>` 也可以。做不到就用上面的 ZIP，兩者結果一樣。

---

## 4. 把 AI 叫到那個資料夾裡

AI 代理要「站在」那個資料夾裡才看得到程式。做法：

1. 打開終端機。
2. 打 `cd ` （**cd 後面有一個空格**），先不要按 Enter。
3. 把剛剛那個資料夾**從桌面直接拖進終端機視窗**——它會自動把路徑填進去。
4. 按 Enter。
5. 打 `claude` 按 Enter。

Claude Code 起來了。現在你可以用中文跟它講話。

---

## 5. 第一句話說什麼

一字不差地打這句：

```
讀 AGENTS.md，幫我把這套系統裝起來。
```

按 Enter。

接下來它會開始問你問題，**一次只問一題**。你就照實回答。

---

## 6. 它問你問題的時候怎麼回

**規則只有一條：講白話，不用裝懂。**

| 它問 | 你可以這樣回 |
|---|---|
| 「你要用哪個 Google 信箱？」 | 直接打你的信箱 |
| 「你班上有幾位學生？」 | `26` |
| 「你要不要業務記錄分頁？」 | `要` 或 `不要` |
| 「這幾種學生記錄類型你要哪幾種？」 | 講編號或名字就好，例如 `第一種和第三種`；**都不要也可以**，回 `都不用` |
| 「這一種還有沒有你自己要記的欄位？」 | 沒有就回 `沒有`；有就講名字，例如 `我要加一個「聯絡方式」` |
| 你聽不懂它在問什麼 | **`我不懂你在問什麼，可以用更白話的說法再講一次嗎？`** |
| 你不知道答案 | **`我不知道，你可以帶我去找嗎？`** |
| 它叫你去某個網站做某件事，你找不到按鈕 | **`我打開了但找不到那個按鈕，畫面上我看到的是……`**（把你看到的字念給它） |
| 你想先跳過某一題 | **`這題我還沒想好，可以先跳過嗎？`** |

**沒有東西是它替你決定的。** 學生記錄要分成哪幾種（導師班級觀察、科任觀察、個案追蹤、
IEP、輔導晤談）、業務記錄要哪幾組——它都是把清單念給你聽讓你勾，**一個都不會預先幫你打勾**。
所以你聽到「我念五種給你聽」的時候，就照你真的在記的東西回答，不用怕漏掉什麼：
之後隨時可以跟它說「我還要加一種」。

**它可能會要你去 Firebase 的網站上點幾下**（建一個資料庫、打開 Google 登入）。
那是整個安裝過程中唯一需要你親手操作的地方。**跟著它一步一步走，做完一件回報一次**，
不要一次做完再說——這樣它才知道你走到哪。

**它做動作之前會先告訴你。** 像是「我接下來要把你的網站放上去，可以嗎」，你回 `可以` 就好。

## 7. 卡住的時候

### 畫面上跳出一堆看不懂的英文

**整段複製，貼給 AI，加一句「這個怎麼辦」。** 就這樣。
不要自己 google、不要慌、不要重開機。那些訊息 AI 讀得懂。

怎麼複製：在終端機裡用滑鼠選取那段文字 → `⌘ + C` → 到 AI 的輸入框 `⌘ + V`。

### AI 好像卡住了、或做錯了

直接說：

- `你剛剛那步好像沒成功，可以檢查一下嗎？`
- `等一下，我覺得這樣不對，先停下來。`
- `我們現在做到第幾步了？`

### 中途要休息，明天再做

可以。它會把進度記在檔案裡。
明天打開終端機、`cd` 進那個資料夾、打 `claude`，然後說：

```
讀 AGENTS.md，接著上次的進度繼續裝。
```

它會自己看進度、從斷掉的地方接下去，**不會把你答過的題目再問一遍**。

### 想確認裝到什麼程度了

跟它說：

```
幫我跑一次健檢，用白話告訴我什麼好了、什麼還沒好。
```

## 8. 有些東西絕對不要貼給任何人

這一節請認真看。

### 絕對不要貼出去的

- **應用程式密碼／App Password**（Google 帳號 → 安全性 → 兩步驟驗證 → 應用程式密碼產生的那一串）
- **任何檔名裡有 `key` 的檔案內容**，例如 `xxx-key.json`、`serviceAccount.json`
- **你的 Google 帳號密碼**（任何人任何理由都不會需要它，包括 AI）
- `.env` 這個檔案的內容

貼出去的後果：拿到的人可以用你的身分讀寫你的資料、寄你的信。

### 「絕對不要」的範圍是誰

**任何人。** 包括同事、包括網路上的技術論壇、包括賣你這套 kit 的人、
也包括你在別的地方開的 AI 對話視窗。

**唯一的例外**是你電腦上正在幫你安裝的那個 AI 代理——但即使是它，
你也**不需要主動把密碼貼給它**：它會直接讀你電腦上的檔案，或叫你用系統的方式設定。
如果有東西（不管是誰）叫你「把密碼貼過來」，先停下來，去問作者。

### 可以貼、不用緊張的

- **Firebase 那六個設定值**（`apiKey`、`authDomain`、`projectId` 那些）。
  名字裡有 key，但它們本來就會出現在網頁原始碼裡，任何人打開你的網站都看得到。
  真正保護你資料的不是它們，是「只有你的 Google 帳號讀得到」那條伺服器規則。
- **錯誤訊息**。全部貼給 AI，越完整越好。

### 學生資料呢

系統設計成**記錄裡一律寫代號**（`S-01`），真名只留在你電腦上的一個名單檔。
所以你之後把記錄拿給 AI 讀、匯出、備份都可以放心。

但要講清楚：**代號不等於匿名**——你自己的名單一對照就知道是誰。
真正擋住別人看的，是那條「只有你的帳號讀得到」的規則。
所以名單檔本身（`data/roster.csv`）不要外流、不要放進任何公開的地方。

## 9. 裝完之後

AI 會給你一個網址，長得像 `https://xxxxx.web.app`。

1. **用手機打開它，登入**（用你剛剛設定的那個 Google 帳號）。
2. 加到手機主畫面：Safari 打開 → 分享鍵 → 「加入主畫面」。以後就像一個 App。
3. 三個分頁試著各記一則。
   學生那一頁最上面有一排你勾的**記錄類型**（例如「導師班級學生紀錄」「個案追蹤」），
   先點你要記的那一種，再點進學生。**同一位學生在不同類型底下是分開的兩本簿子**，
   互相看不到——這就是它們分開的用意。

之後你有兩種記錄方式：

- **直接在網頁上打字**——手機、電腦都行。
- **錄音**：上完課拿手機錄一段話，傳到電腦、丟進 kit 資料夾裡的 `inbox/`，
  然後跟 AI 說「整理成學生記錄」（或課程記錄／會議紀錄）。
  它會轉成文字、改寫、念給你確認，**你點頭它才寫進去**。
  錄音跟轉出來的文字全程都在你自己的電腦上。

想知道每個分頁該準備什麼、學生記錄有哪五種類型、業務記錄有哪些組
→ 讀 `docs/DATA-CHECKLIST.md` 跟 `docs/BUSINESS-GROUPS.md`。
不想讀也行，直接問 AI：`業務記錄那頁我該記什麼？`

在網頁上自己加了一種記錄類型或一組業務？**加完回頭跟 AI 說一聲**
（「我在網頁上加了一種○○，幫我寫進設定」），不然那一種只有網頁看得到。

## 10. 常用的幾句話（存起來，之後用得到）

```
幫我同步一下。
幫我備份一次。
這個月誰還沒記？
把 S-03 這學期的記錄整理成家長會要講的重點。
我還要加一組業務記錄，是關於○○的。
我還要一種學生記錄類型，是記○○的。
把 S-07 列入個案追蹤。
幫我跑一次健檢，用白話告訴我結果。
inbox 裡有一個錄音，幫我整理成課程記錄。
```
