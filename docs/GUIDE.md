# 給老師的入門：從「我沒用過 AI」開始

這份文件假設你**完全沒有碰過 AI 代理、沒有開過終端機、不知道 GitHub 是什麼**。
沒關係，這些東西比想像中簡單，而且大部分事情是 AI 幫你做，不是你做。

全部走完大約 30 到 60 分鐘，其中大半是等程式安裝。

---

## 0. 先弄懂三個名詞（只有三個）

**AI 代理**
你用過 ChatGPT 那種「打字問它、它回你」的 AI 吧？AI 代理是它的另一種樣子：
除了跟你講話，它還**能真的動你電腦上的檔案、真的執行程式**。
所以你可以對它說「幫我把這套系統裝起來」，它會真的去裝，而不是告訴你「你可以這樣做……」。

**終端機（Terminal）**
你電腦上一個黑底白字的視窗，用打字下指令。
你**幾乎不用自己打任何指令**——它只是 AI 代理住的地方。你打開它、把 AI 叫起來，之後就用中文跟 AI 講話。

**Repo（程式資料夾）**
就是一個資料夾，裡面裝著這套系統的程式。你會把它下載到你的電腦上。

---

## 1. 把這套系統下載到你的電腦

作者會寄一封 GitHub 邀請信給你（寄件人是 GitHub，主旨大概是
「… invited you to collaborate on …」）。

1. **開信，按信裡的綠色按鈕**（`View invitation` 或 `Accept invitation`）。
2. 網頁會打開 GitHub。沒有 GitHub 帳號的話它會請你先註冊一個（免費，用你的信箱就好）。
3. 按 **`Accept invitation`**。
4. 接受之後你會進到這個 repo 的頁面。找到右上方那顆綠色的 **`Code`** 按鈕，點它。
5. 下拉選單最下面有 **`Download ZIP`**，點下去。
6. 下載好的 zip 檔在你的「下載項目」資料夾。
   - macOS：**點兩下解開它**。
   - Windows：在那個 zip 上**按右鍵 →「全部解壓縮」**，按「解壓縮」。
   然後把解開的那個資料夾**拖到桌面**（放哪裡都行，但桌面最好找）。

> **Windows 的人注意**：不要把它放進 OneDrive 裡面（檔案會被鎖住）。
> 桌面如果本身就被 OneDrive 同步了，就放 `C:\Users\你的名字\` 底下。

> **懂一點電腦、想用 git 的話**：`Code` 按鈕裡有一段 `git clone https://github.com/...` 的網址，
> 在終端機打 `git clone <那段網址>` 也可以。做不到就用上面的 ZIP，兩者結果一樣。

## 2. 跑一次 bootstrap（它會把該裝的都裝好，包括 AI 代理）

**你不用自己先去裝 AI 代理。** 這個資料夾裡有一支叫 bootstrap 的腳本，
它會把 git、Python、Node.js 裝好，問你訂的是哪一家 AI 並把那一家的 CLI 裝起來，
最後再把其餘工具裝齊、跑一次健檢。

### Windows：按兩下就好

打開剛剛那個資料夾裡的 `setup`，對 **`bootstrap.cmd`** 按兩下。
會跳出一個黑色視窗自己跑起來，**中途問「要不要允許這個程式變更你的裝置」就按「是」**。
跑完它會停在那裡等你按鍵。這一步你完全不用打字。

### macOS：開終端機，貼一行

先開終端機——三種方法挑一個：

- **最快**：按 `⌘ + 空白鍵`（Spotlight 搜尋）→ 打 `terminal` → 按 Enter。
- 或：打開「應用程式」→「工具程式」→「終端機」。
- 或：Launchpad → 搜尋「終端機」。

打開之後你會看到一個視窗，裡面有一行字然後一個游標在閃。**那就對了。**
你要做的只有兩件事：**貼上文字**（`⌘ + V`）跟**按 Enter**。

> 覺得字太小 → 選單「終端機」→「設定」→ 調字級。眼睛比較舒服，你等一下會盯著它一陣子。

然後：

1. 打 `cd ` （**cd 後面有一個空格**），先不要按 Enter。
2. 把桌面上那個資料夾**直接拖進終端機視窗**——它會自動把路徑填進去。按 Enter。
3. 貼上這一行，按 Enter：

```
bash setup/bootstrap.sh
```

### 它會問你一題

**你訂的是哪一家 AI？** 你手上有哪一家的訂閱就選哪一家：

```
  1) Claude Code（你有 Claude 訂閱）
  2) OpenAI Codex CLI（你有 ChatGPT 訂閱）
  3) Gemini CLI（你有 Google 帳號）
  4) 先不要裝，我自己來
```

打數字按 Enter（直接按 Enter ＝ 1）。接著它再問一次「可以開始了嗎」，按 Enter 繼續。

### 接下來會發生什麼

它會一項一項裝，螢幕上一直捲字，**這是正常的**，10 到 25 分鐘。中間可能會：

- **macOS**：跳出一個視窗說要裝「命令列工具」——按「安裝」，等它跑完
  （幾分鐘到十幾分鐘）。裝完**回到終端機，把 `bash setup/bootstrap.sh` 再貼一次**。
  另外它可能會問你的**開機密碼**，打進去按 Enter（畫面上不會顯示任何字，正常）。
- **Windows**：跳出「使用者帳戶控制」的視窗，按「是」。

跑完最後它會印出三行字，告訴你下一步要做什麼。**那三行就是下面兩節在講的事。**

> 某一項沒裝成也不會卡住——它會印出那個工具的官方網址繼續往下走，
> 最後的健檢會告訴你缺什麼。重跑一次 bootstrap 是安全的，已經裝好的會自動跳過。

## 3. 重開終端機，把 AI 叫起來

**關掉終端機視窗（Windows 是關掉那個黑色視窗），重新開一個新的。**
剛裝好的程式要新視窗才叫得到，這一步不能省。

Windows 開新視窗的方法：按 **Windows 鍵** → 打 `terminal` 或 `PowerShell` → 按 Enter。
用「Windows Terminal」或「PowerShell」都可以，**不要用 WSL、不要用 cmd**。
貼上文字是 `Ctrl + V`。

然後：

1. 打 `cd ` （**cd 後面有一個空格**），把那個資料夾拖進視窗，按 Enter。
2. 打你剛剛裝的那一家，按 Enter：
   - Claude Code → `claude`
   - Codex CLI → `codex`
   - Gemini CLI → `gemini`

**第一次啟動它會請你登入。** 它會在瀏覽器開一個頁面，你用自己那家的帳號
（Claude／ChatGPT／Google）登入、按同意，回到終端機就好了。

登入完，AI 代理就起來了。現在你可以用中文跟它講話。

## 4. 第一句話說什麼

一字不差地打這句：

```
讀 AGENTS.md，幫我把這套系統裝起來。
```

按 Enter。

（bootstrap 跑完印的那三行裡也有一句一樣意思的，直接照貼也可以。）

接下來它會開始問你問題，**一次只問一題**。你就照實回答。

---

## 5. 它問你問題的時候怎麼回

**規則只有一條：講白話，不用裝懂。**

| 它問 | 你可以這樣回 |
|---|---|
| 「你要用哪個 Google 信箱？」 | 直接打你的信箱 |
| 「你班上有幾位學生？」 | `26` |
| 「你要不要業務記錄分頁？」 | `要` 或 `不要` |
| 「這幾種學生記錄類型你要哪幾種？」 | 講編號或名字就好，例如 `第一種和第三種`；**都不要也可以**，回 `都不用` |
| 「這一種還有沒有你自己要記的欄位？」 | 沒有就回 `沒有`；有就講名字，例如 `我要加一個「聯絡方式」` |
| 你聽不懂它在問什麼 | **`我不懂你在問什麼，可以用更白話的說法再講一次嗎？`** |
| 你不知道答案 | **`我不知道，你可以帶我去找嗎？`** |
| 它叫你去某個網站做某件事，你找不到按鈕 | **`我打開了但找不到那個按鈕，畫面上我看到的是……`**（把你看到的字念給它） |
| 你想先跳過某一題 | **`這題我還沒想好，可以先跳過嗎？`** |

**它會先問你一句「你最像哪一種？」** ①實驗教育／私校老師的質性評量 ②特教／早療的 IEP 目標追蹤
③諮商／教練／社工的 SOAP 個案紀錄 ④都不是。選了之後它會**唸出**那一種老師通常會勾的東西給你聽
——**那只是唸給你聽，一項都不會幫你打勾**，選④照樣裝得起來。

**沒有東西是它替你決定的。** 學生記錄要分成哪幾種（質性評量觀察、導師班級觀察、科任觀察、
個案追蹤、IEP／早療目標追蹤、會談紀錄）、業務記錄要哪幾組——它都是把清單念給你聽讓你勾，
**一個都不會預先幫你打勾**。所以你聽到它念清單的時候，就照你真的在記的東西回答，
不用怕漏掉什麼：之後隨時可以跟它說「我還要加一種」。

**它可能會要你去 Firebase 的網站上點幾下**（建一個資料庫、打開 Google 登入）。
那是整個安裝過程中唯一需要你親手操作的地方。**跟著它一步一步走，做完一件回報一次**，
不要一次做完再說——這樣它才知道你走到哪。

**它做動作之前會先告訴你。** 像是「我接下來要把你的網站放上去，可以嗎」，你回 `可以` 就好。

## 6. 卡住的時候

### 畫面上跳出一堆看不懂的英文

**整段複製，貼給 AI，加一句「這個怎麼辦」。** 就這樣。
不要自己 google、不要慌、不要重開機。那些訊息 AI 讀得懂。

怎麼複製：在終端機裡用滑鼠選取那段文字 → `⌘ + C` → 到 AI 的輸入框 `⌘ + V`。

### AI 好像卡住了、或做錯了

直接說：

- `你剛剛那步好像沒成功，可以檢查一下嗎？`
- `等一下，我覺得這樣不對，先停下來。`
- `我們現在做到第幾步了？`

### 中途要休息，明天再做

可以。它會把進度記在檔案裡。
明天打開終端機、`cd` 進那個資料夾、打 `claude`，然後說：

```
讀 AGENTS.md，接著上次的進度繼續裝。
```

它會自己看進度、從斷掉的地方接下去，**不會把你答過的題目再問一遍**。

### 想確認裝到什麼程度了

跟它說：

```
幫我跑一次健檢，用白話告訴我什麼好了、什麼還沒好。
```

## 7. 有些東西絕對不要貼給任何人

這一節請認真看。

### 絕對不要貼出去的

- **應用程式密碼／App Password**（Google 帳號 → 安全性 → 兩步驟驗證 → 應用程式密碼產生的那一串）
- **任何檔名裡有 `key` 的檔案內容**，例如 `xxx-key.json`、`serviceAccount.json`
- **你的 Google 帳號密碼**（任何人任何理由都不會需要它，包括 AI）
- `.env` 這個檔案的內容

貼出去的後果：拿到的人可以用你的身分讀寫你的資料、寄你的信。

### 「絕對不要」的範圍是誰

**任何人。** 包括同事、包括網路上的技術論壇、包括賣你這套 kit 的人、
也包括你在別的地方開的 AI 對話視窗。

**唯一的例外**是你電腦上正在幫你安裝的那個 AI 代理——但即使是它，
你也**不需要主動把密碼貼給它**：它會直接讀你電腦上的檔案，或叫你用系統的方式設定。
如果有東西（不管是誰）叫你「把密碼貼過來」，先停下來，去問作者。

### 可以貼、不用緊張的

- **Firebase 那六個設定值**（`apiKey`、`authDomain`、`projectId` 那些）。
  名字裡有 key，但它們本來就會出現在網頁原始碼裡，任何人打開你的網站都看得到。
  真正保護你資料的不是它們，是「只有你的 Google 帳號讀得到」那條伺服器規則。
- **錯誤訊息**。全部貼給 AI，越完整越好。

### 學生資料呢

系統設計成**記錄裡一律寫代號**（`S-01`），真名只留在你電腦上的一個名單檔。
所以你之後把記錄拿給 AI 讀、匯出、備份都可以放心。

但要講清楚：**代號不等於匿名**——你自己的名單一對照就知道是誰。
真正擋住別人看的，是那條「只有你的帳號讀得到」的規則。
所以名單檔本身（`data/roster.csv`）不要外流、不要放進任何公開的地方。

## 8. 裝完之後

AI 會給你一個網址，長得像 `https://xxxxx.web.app`。
（安裝時選了「只放這台電腦」的話沒有網址，直接跳到下面那兩點選用的東西。）

1. **用手機打開它，登入**（用你剛剛設定的那個 Google 帳號）。
2. 加到手機主畫面：Safari 打開 → 分享鍵 → 「加入主畫面」。以後就像一個 App。
3. 三個分頁試著各記一則。
   學生那一頁最上面有一排你勾的**記錄類型**（例如「導師班級學生紀錄」「個案追蹤」），
   先點你要記的那一種，再點進學生。**同一位學生在不同類型底下是分開的兩本簿子**，
   互相看不到——這就是它們分開的用意。

之後你有兩種記錄方式：

- **直接在網頁上打字**——手機、電腦都行。
- **錄音**：上完課拿手機錄一段話，傳到電腦、丟進 kit 資料夾裡的 `inbox/`，
  然後跟 AI 說「整理成學生記錄」（或課程記錄／會議紀錄）。
  它會轉成文字、改寫、念給你確認，**你點頭它才寫進去**。
  錄音跟轉出來的文字全程都在你自己的電腦上。

另外有兩個**選用**的東西，你裝的時候選了才有：

- **本機模式**：如果你在 AI 精靈問「你的紀錄要放哪裡」那一題選了「只放這台電腦」，那就**沒有網址、沒有網頁、
  也不用同步**——上面第 1、2 點跳過。你的紀錄就是電腦上 `data/` 底下的文字檔，
  其他（錄音、匯出 Word、期末素材包、備份到雲端硬碟）全部照用。之後想改成雲端隨時可以，
  跟 AI 說「我想改成雲端」就好，**已經寫的紀錄一則都不會動**。
- **用 LINE 交辦**：裝了的話，你在外面對那個 LINE 帳號講一句
  「今天午休 S-01 主動幫忙排椅子」，回家電腦醒著的時候它自己就寫進去了，
  手機上會收到一則回報告訴你記到哪裡。沒裝也完全不影響其他功能。

想知道每個分頁該準備什麼、學生記錄有哪幾種類型、期末會產出什麼、業務記錄有哪些組
→ 讀 `docs/DATA-CHECKLIST.md` 跟 `docs/BUSINESS-GROUPS.md`。
不想讀也行，直接問 AI：`業務記錄那頁我該記什麼？`

在網頁上自己加了一種記錄類型或一組業務？**加完回頭跟 AI 說一聲**
（「我在網頁上加了一種○○，幫我寫進設定」），不然那一種只有網頁看得到。

## 9. 常用的幾句話（存起來，之後用得到）

```
幫我同步一下。
幫我備份一次。
這個月誰還沒記？
把 S-03 這學期的記錄整理成家長會要講的重點。
幫我把 S-03 的記錄匯出成 Word。
幫我把 S-02 的 IEP 目標記進去。
這段錄音是第 3 次會談，整理成 SOAP。
幫我產生 S-01 的期末素材包。
我還要加一組業務記錄，是關於○○的。
我還要一種學生記錄類型，是記○○的。
把 S-07 列入個案追蹤。
幫我跑一次健檢，用白話告訴我結果。
inbox 裡有一個錄音，幫我整理成課程記錄。
```
