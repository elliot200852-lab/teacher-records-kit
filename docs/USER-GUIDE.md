# 教學記錄 kit・老師操作書

> 適用版本 `3.0.0-alpha.6`。
> 這一本給**沒裝過軟體、沒用過 AI、看到黑色視窗會緊張**的老師。
> 寫法是「你會看到什麼畫面，然後按哪裡」。
> 已經熟電腦、想看每一個指令跟旗標的人，請看另一本 `docs/PRODUCT-MANUAL.md`。

---

## 這本書怎麼讀

- **從頭讀到「裝完之後」那一章就夠了**，後面幾章是查的，不是背的。
- 書裡的圖分兩種：**黑框方塊**是電腦螢幕上會跑出來的字（你不用打，看懂就好）；
  **照片**是網頁真正的樣子。
- 圖裡的學生（林小安、陳品叡…）跟他們的紀錄**全是假的**，是系統內建的示範資料。
- 全部裝完大約 **30 到 60 分鐘**，其中大半是站起來去泡茶、等程式自己裝完的時間。
- **你幾乎不用自己打任何指令。** 你要做的事是：回答問題、點幾個網頁按鈕、把看不懂的字貼給 AI 看。

### 先弄懂三個名詞（真的只有三個）

| 名詞 | 一句話 |
|---|---|
| **AI 代理** | 你用過 ChatGPT 那種會打字回你的 AI 吧？AI 代理是它的另一個樣子：**它能真的動你電腦上的檔案、真的執行程式**。所以你可以對它說「幫我把這套系統裝起來」，它會真的去裝 |
| **終端機** | 你電腦上一個黑底白字的視窗。它只是 AI 代理住的地方，**你打開它、把 AI 叫起來，之後就用中文跟 AI 講話** |
| **資料夾（repo）** | 就是一個資料夾，裡面裝著這套系統的程式。你會把它下載到你的電腦上 |

# 一、這是什麼、你會拿到什麼

## 1-1 一句話

你拿到一個資料夾。把它交給你自己訂的 AI，說「讀 AGENTS.md，幫我裝起來」，
一小時後你會有一個**只有你自己看得到的教學記錄網站**——電腦打得開，手機也打得開，
下課走廊上就能記一則。

![電腦上打開的樣子：上面是三個分頁，中間是你勾的記錄類型，下面是全班每一位一張卡](img/01-desktop-overview.png)

## 1-2 你會拿到這幾樣

| 拿到什麼 | 一句話 |
|---|---|
| **三個分頁** | 學生記錄、課程記錄、業務記錄。要不要開、裡面記什麼，全部由你勾 |
| **手機隨時記錄** | 網址加到手機主畫面就像一個 App，下課走廊上就能記；沒訊號也打得開 |
| **資料完全在你自己的帳號裡** | 資料庫、雲端硬碟、網址全部開在你名下。賣你這套東西的人沒有金鑰、沒有帳號、沒有副本 |
| **紀錄裡不寫真名** | 記錄正文一律寫 `S-01` 這種代號，真名只存在你電腦上的一個名單檔 |
| **期末素材包** | 一個動作，把整年的零碎紀錄依報告格式分好組，你的 AI 照著寫草稿，你定稿 |
| **錄音就能記** | 上完課錄一段話，AI 轉成文字、整理成紀錄、念給你確認，你點頭它才寫進去 |

**這套不做的事**（免得你等）：沒有家長端、沒有給別的老師共用、不會自動幫你打分數或自動生成評語、
作者不會也不能介入你的資料。

## 1-3 兩件你要先想一下的事

安裝的時候 AI 會問你這兩題。現在先看一眼，心裡有個底就好。

### 第一題：你的紀錄要放哪裡

| | **雲端**（大部分人選這個） | **只放這台電腦** |
|---|---|---|
| 手機上有一頁網頁、電腦跟手機自動同步 | 有 | **沒有** |
| 要申請一個資料庫、填六個設定值 | 要，大概多花十分鐘 | **完全不用** |
| 錄音轉文字、Word／PDF、期末素材包、家長信、備份到雲端硬碟 | 有 | **一樣有** |
| 帳單 | 你自己的（一般老師的用量都在免費額度裡） | 沒有 |

**哪個比較安全沒有標準答案，兩邊的風險長得不一樣**：雲端要相信你的 Google 帳號不會被盜
（所以請開兩步驟驗證）；只放這台電腦要相信你的電腦不會壞、不會掉（所以備份那一步更不能省）。

會在走廊上、車上隨手記的人選雲端。只在自己書桌前寫、而且對雲端就是不安心的人選本機。
**選了本機之後隨時可以改成雲端，已經記的東西一則都不會動**——跟 AI 說一句「我想改成雲端」就好。

### 第二題：要不要用 LINE 交辦

裝了這一項之後，你在校門口對一個 LINE 帳號講一句
「今天午休 S-01 主動幫忙排椅子」，回家電腦醒著的時候，紀錄就自己寫好了，手機上會收到一則回報。

**要先知道三件事**：① **要綁一張信用卡**——收訊息的那一小段程式不能跑在免費方案上，
Google 規定升級成「用多少算多少」的方案要綁卡。你這個用量幾乎一定是 **0 元**，但卡要綁
（可以在帳單頁面設一個「超過 1 美元就寄信通知我」的提醒）。
② **只有雲端模式有**，選「只放這台電腦」的人 AI 不會問這一題。
③ **電腦要醒著才會寫進去**——訊息乖乖排在雲端一則都不會掉，但整理成紀錄是在你電腦上做的。

**不想綁卡就不要開這一項，其他功能一項都不受影響。** 直接跟 AI 說「不要」，它不會再提。
（裝好之後怎麼用，看 §3-4。）

## 1-4 三個分頁，各記什麼

| 分頁 | 記什麼 | 一張卡是什麼 |
|---|---|---|
| **學生記錄** | 你對某一位學生的具體觀察 | 一位學生一張 |
| **課程記錄** | 課本身——講到哪、實際教了什麼、整體反應、下次要調整什麼 | 一門課一張 |
| **業務記錄** | 教學以外你每天在處理的事：班務、公文、會議、輔導個案、研習、報帳 | 一組業務一張 |

學生那一頁底下**還會再分一層「記錄類型」**。這很重要，講清楚：

期末要寫文字評語的觀察、導師對全班的日常觀察、科任老師的課堂觀察、個案追蹤、IEP 目標追蹤、
會談紀錄（SOAP）——**這是幾本不一樣的簿子**，各有各的欄位、各有各的分類詞。
同一位學生在「導師班級學生紀錄」寫的東西，**不會**出現在「個案追蹤」裡。這就是它們分開的用意。

**沒有任何一種是系統替你決定的。** AI 會把清單念給你聽讓你自己勾，一種都不勾也是合法的答案，
之後隨時可以加。

# 二、安裝：從一台什麼都沒裝的電腦開始

四個動作：**① 拿到資料夾 ② 跑 bootstrap ③ 重開終端機、登入你的 AI ④ 說第一句話**。
之後 AI 帶你走 0 到 11 步，你只要回答關於你自己的問題。

## 2-1 ① 拿到資料夾

這個專案已完全公開免費開放（Public），任何人都可以直接下載使用，不需要等待邀請信：

1. **開啟專案網頁**：[https://github.com/elliot200852-lab/teacher-records-kit](https://github.com/elliot200852-lab/teacher-records-kit)
2. 找右上方那顆綠色的 **`Code`** 按鈕 → 下拉選單**最下面**的 **`Download ZIP`**。
3. 下載好的檔案在「下載項目」裡。macOS **點兩下**它就解開了；
   Windows 在那個檔案上**按右鍵 →「全部解壓縮」**。
4. （如果你習慣使用 Git，也可以直接在終端機執行 `git clone https://github.com/elliot200852-lab/teacher-records-kit.git`）

**放在哪裡**：路徑短、好找。

| 平台 | 建議放這裡 | **不要放這裡** |
|---|---|---|
| macOS | 桌面，或使用者資料夾底下 | iCloud 的「桌面與文件」同步夾 |
| Windows | `C:\Users\你的名字\teacher-records-kit` | **OneDrive 底下**（檔案會被鎖住、你的真名名單會被同步上雲）、路徑很長的地方 |

## 2-2 ② 跑 bootstrap（它會把該裝的都裝好，包括 AI）

**你不用自己先去裝 AI。** 這個資料夾裡有一支叫 bootstrap 的腳本，
它會把該裝的東西（git、Python、Node.js、你選的那一家 AI、還有幾個小工具）一次裝齊。

### Windows：按兩下就好

打開剛剛那個資料夾裡的 `setup`，對 **`bootstrap.cmd`** 按兩下。
黑色視窗會自己跑起來，**中途問「要不要允許這個程式變更你的裝置」就按「是」**。
跑完它會停在那裡等你按鍵。這一步你完全不用打字。

### macOS：開終端機，貼一行

先把終端機打開，三種方法挑一個：

- **最快**：按 `⌘ + 空白鍵` → 打 `terminal` → 按 Enter。
- 或：「應用程式」→「工具程式」→「終端機」。
- 或：Launchpad → 搜尋「終端機」。

打開之後你會看到一個視窗，裡面一行字，後面一個游標在閃。**那就對了。**
你要做的只有兩件事：**貼上文字**（`⌘ + V`）跟**按 Enter**。

> 覺得字太小 → 選單「終端機」→「設定」→ 調字級。你等一下會盯著它一陣子，眼睛舒服比較重要。

然後：

1. 打 `cd ` （**cd 後面有一個空格**），先不要按 Enter。
2. 把剛剛那個資料夾**直接拖進終端機視窗**——路徑會自己填進去。按 Enter。
3. 貼上這一行，按 Enter：

```
bash setup/bootstrap.sh
```

### 它只問你一題

**你訂的是哪一家 AI？** 手上有哪一家的訂閱就選哪一家：

```
  1) Claude Code（你有 Claude 訂閱）
  2) OpenAI Codex CLI（你有 ChatGPT 訂閱）
  3) Gemini CLI（你有 Google 帳號）
  4) 先不要裝，我自己來
```

打數字按 Enter（**直接按 Enter ＝ 1**）。接著它再問一次「可以開始了嗎」，按 Enter 繼續。

### 畫面上會看到

它會一項一項往下裝，**螢幕上一直捲字，這是正常的**。每一項都會先說「為什麼需要它」，
裝好的會直接跳過。下面這一段是真的跑出來的樣子（這一次加了「只看不裝」的旗標，所以每一項都寫著跳過）：

```
教學記錄 kit：地基安裝（macOS／arm64）
資料夾：/Users/你的名字/teacher-records-kit

── Xcode 命令列工具（macOS 的 git、編譯器都在裡面）
  ✓ 已經有了（/Library/Developer/CommandLineTools）

── Homebrew（macOS 上裝東西的套件管理程式）
  ✓ 已經有了（/opt/homebrew/bin/brew）

── git、Python 3、Node.js
  ✓ git 2.54.0、Python 3.14.5、Node v24.13.0 都夠新，跳過。

── 其餘工具（Firebase CLI、gcloud、ffmpeg、語音轉逐字稿）
── firebase
   為什麼需要：Firebase CLI（部署安全規則與網站）
  ✓ 已就緒，跳過
── whisper-cli
   為什麼需要：whisper.cpp（本機語音轉逐字稿，錄音不出本機）
  ✓ 已就緒，跳過

完成：就緒 5、剛裝好 0、要手動 0、失敗 0
下一步：python3 scripts/doctor.py 逐項健檢
```

### 中間可能跳出來的東西（都是正常的）

- **macOS**：跳出一個系統視窗說要裝「命令列工具」→ 按「安裝」，等它跑完（幾分鐘到十幾分鐘）。
  **裝完回到終端機，把 `bash setup/bootstrap.sh` 再貼一次**——腳本在這裡會刻意停下來等你。
- **macOS**：它可能會問你的**開機密碼**。打進去按 Enter。**畫面上不會顯示任何字，這是正常的。**
- **Windows**：跳出「使用者帳戶控制」→ 按「是」。不需要系統管理員身分。
- **要多久**：網路正常的話 10 到 25 分鐘。

> **某一項沒裝成也不會卡住。** 它會把那個工具的官方網址印出來，繼續往下走，
> 最後的健檢會告訴你到底缺什麼。**重跑一次 bootstrap 是安全的**，裝好的會自動跳過。

### 跑完它會印出三行字

```
════════════════════════════════════════════════════════
地基鋪好了。接下來三個動作：

  ① 關掉這個終端機視窗，重新開一個新的（剛裝好的程式要新視窗才叫得到）。
  ② 在新視窗裡貼這一行，切到這個資料夾：

        cd "/Users/你的名字/teacher-records-kit"

  ③ 把你的 AI 代理叫起來（claude／codex／gemini 都行），對它說：

        請完整讀 AGENTS.md，然後帶我從步驟 0 開始安裝
════════════════════════════════════════════════════════
```

**那三行就是下面兩節在講的事。** 照著做就好。

## 2-3 ③ 重開終端機，把 AI 叫起來

**關掉終端機視窗，重新開一個新的。這一步不能省**——剛裝好的程式要新視窗才叫得到。
（Windows 是關掉那個黑色視窗，然後按 Windows 鍵 → 打 `terminal` 或 `PowerShell` → Enter。
用「Windows Terminal」或「PowerShell」都可以，**不要用 WSL、不要用 cmd**。貼上文字是 `Ctrl + V`。）

新視窗裡：

1. 打 `cd ` （**後面一個空格**），把資料夾拖進去，按 Enter。
2. 打你剛剛裝的那一家，按 Enter：
   - Claude Code → `claude`
   - Codex CLI → `codex`
   - Gemini CLI → `gemini`

**第一次啟動它會請你登入。** 它會在瀏覽器開一個頁面，你用自己那家的帳號
（Claude／ChatGPT／Google）登入、按同意，回到終端機就好了。

登入完，AI 就起來了。**現在你可以用中文跟它講話。**

## 2-4 ④ 第一句話說什麼

一字不差地打這一句，按 Enter：

```
讀 AGENTS.md，幫我把這套系統裝起來。
```

三家 AI 的第一句話是同一句。接下來它會開始問你問題，**一次只問一題**。

## 2-5 ⑤ AI 會問你的 0 到 11 步

進度它自己記著，**中途休息明天再接都可以**，答過的題目不會再問你一次。

| 步驟 | AI 在做什麼 | **你要準備什麼** |
|---|---|---|
| **0** 看現況 | 先看你電腦上有沒有裝過，判斷是新裝、續裝，還是從舊版升級 | 不用準備。它自己看完才開口 |
| **1** 裝工具 | 跑過 bootstrap 的話只做確認 | 可能要輸入開機密碼（macOS）或按「是」（Windows） |
| **2** 紀錄放哪裡 | **先問「雲端還是只放這台電腦」**；選雲端才陪你去申請 | **一個能自己申請服務的 Google 信箱**（選本機完全不用） |
| **3** 三個分頁要記什麼 | 先問「你最像哪一種老師」，再把清單一條一條念給你勾 | 記錄類型、課名、業務組；IEP 的目標、SOAP 的個案概念化 |
| **4** 產生設定與規定 | 寫設定檔，然後把「只有你看得到」那條規定送上你的資料庫 | 不用準備 |
| **5** 上線 | 把網頁放到網路上，給你一個網址 | 不用準備 |
| **6** 名單與舊資料 | 把你的學生名單填進去；舊紀錄一則一則搬 | **學生名單**（座號＋姓名就夠）。有舊的電子檔一併給它 |
| **7** 備份夾 | 設定每週把你所有紀錄打包一份，放到你自己的雲端硬碟 | **裝好並登入「Google 雲端硬碟」那個程式，在雲端硬碟裡開一個資料夾** |
| **8** 排程（選用） | 掛每天早上同步一次、每週日備份一次 | 不用準備 |
| **9** 錄音試跑 | 帶你走一次錄音 → 逐字稿 → 紀錄 | **用手機隨便錄一段三十秒的話** |
| **10** 驗收 | 九件事逐項做、逐項回報 | 你的手機、你的瀏覽器、你的雲端硬碟 |
| **11** LINE 交辦（選用） | 開一個 LINE 帳號、部署一支小程式、配對你的手機 | 綁卡升級、一個 LINE 開發者帳號。**不要就直接說不要** |

### 它問你問題的時候怎麼回

**規則只有一條：講白話，不用裝懂。**

| 它問 | 你可以這樣回 |
|---|---|
| 「你要用哪個 Google 信箱？」 | 直接打你的信箱 |
| 「你班上有幾位學生？」 | `26` |
| 「這幾種記錄類型你要哪幾種？」 | 講編號或名字就好，例如 `第一種和第三種`；**都不要也可以**，回 `都不用` |
| 「這一種還有沒有你自己要記的欄位？」 | 沒有就回 `沒有`；有就講名字，例如 `我要加一個「聯絡方式」` |
| 你聽不懂它在問什麼 | **`我不懂你在問什麼，可以用更白話的說法再講一次嗎？`** |
| 你不知道答案 | **`我不知道，你可以帶我去找嗎？`** |
| 它叫你去某個網站點某個按鈕，你找不到 | **`我打開了但找不到那個按鈕，畫面上我看到的是……`**（把你看到的字念給它） |
| 你想先跳過某一題 | **`這題我還沒想好，可以先跳過嗎？`** |

### 步驟 2：它會這樣問你第一題

這是整個安裝的第一個實質問題。它會照這個講法問（你會看到很接近下面這一段的話）：

> 「開始之前先決定一件事，因為它會決定後面要不要申請帳號。**你的紀錄要放哪裡？**
>
> ① **雲端**——我幫你開一個屬於你自己的資料庫。好處是：**手機上有一頁網頁**，
> 你排隊、等車、下課走廊上都能隨手記一則，電腦跟手機自動同步。
>
> ② **只放這台電腦**——完全不碰雲端：不用申請任何東西、沒有網頁、沒有帳單、沒有要填的值。
>
> 兩種都是完整的。**差別只有「手機上那一頁網頁」跟「同步」。**
> 而且**哪天想改都可以**，已經記的東西一則都不會動。你要哪一種？」

**選雲端的話，這是整個安裝裡唯一要你親手點網頁的地方。** AI 會帶你一格一格走，
在那個網站上完成四件事（申請一個專案、開一個資料庫、打開 Google 登入、拿到六個設定值）。
**找不到按鈕就把畫面上的字念給它聽**，它會帶你找。

> **兩個一定要知道的坑**
>
> **① 學校帳號常常被鎖住。** 判斷方法是實際做一次：用那個帳號登入、按「建立專案」。
> 建得出來就能用；看到「你的機構不允許建立專案」就不行。不行的話用你自己的個人 Gmail
> （資料在你私人帳號裡，學校換人、你調校都不影響），或找資訊組開權限。
>
> **② 整套安裝從頭到尾只用那一個信箱。** 申請時登入的、設定裡填的、之後打開網站登入的，
> **三處必須是同一個**，不然你會看到「無權檢視」。

### 步驟 3：三個分頁要想清楚的

它會先問一句「**你最像哪一種？**」（① 實驗教育／私校的質性評量 ② 特教／早療的 IEP 目標追蹤
③ 諮商／教練／社工的 SOAP 個案紀錄 ④ 都不是）。選完它會**唸出**那一種老師通常會勾的東西，
然後接這一句：

> 「以上只是建議——下面每一項還是你自己勾，我不會替你打勾。」

**它說到做到。** 選 ④ 照樣裝得起來。你要想清楚的是：學生那頁**要哪幾種記錄類型**、
班上幾位、個案型的類型先列入誰；課程那頁先建哪幾門（課名＋主課程或科任，一門都不先建也行）；
業務那頁十一組裡哪幾組是你手上真的在跑的線。

勾了 **IEP** 的，先把該生的目標找出來：**領域／學年目標／學期目標／評量方式／評量標準／期程**，
一條一條講給它聽，編號（G1、G2…）它來編。
勾了 **SOAP** 的，先想好**五格**（主訴／背景／評估假設／處遇目標／結案標準）。
**兩者現在講不出來都可以先空著，之後補。**

勾了**導師班級學生紀錄**、而且選雲端的，它會多問一題「**要不要開評量維度自動補標**」：
每次同步完，讓你電腦上的 AI 讀一讀還沒有維度標籤的紀錄、照實補上 `#人際` 這種標籤。
送出去的只有代號跟正文、只加不刪、會用到那支 AI 的額度。**不確定就先說不要**，之後隨時能開（§3-3 有講它平常長怎樣）。

### 步驟 6：名單長什麼樣

三欄，第一欄座號或代號、第二欄姓名、第三欄留空或填個案型類型：

```
代號,姓名,類型
01,學生甲,
02,學生乙,case
03,學生丙,case;iep
```

**第二欄是整套系統裡唯一有真名的地方**，它只存在你自己這台電腦上。
手上有校務系統匯出的檔就給 AI，它幫你轉；沒有就直接念，它幫你打。

### 步驟 7：備份夾（不要省）

1. 下載並安裝「Google 雲端硬碟」桌面程式（<https://www.google.com/drive/download/>），
   用**同一個** Google 帳號登入它。
2. 打開你的雲端硬碟，建一個資料夾，例如「教學紀錄備份」。
3. **怎麼確認做對了**：macOS 打開 Finder、Windows 打開檔案總管，側邊欄會多出「Google Drive」。
   點進去看得到你剛剛建的那個資料夾，就對了。

路徑不用你自己找，安裝精靈會自動偵測、把它當預設值填好。

### 步驟 9：錄音試跑一次（這一步不要跳）

錄音是這套系統最省力的入口，**但你不會自己想到要怎麼用**，所以 AI 會帶你走一遍。

用手機隨便錄一段三十秒的話，傳到電腦，丟進資料夾裡的 `inbox/` 那個夾子
（macOS 用 AirDrop；Windows 用「手機連結」、LINE 傳給自己再下載、或 USB 線），
跟 AI 說一聲，它就會轉文字。第一次會下載一個約 1.6 GB 的語音模型，之後就不用再下載。

**最重要的一句話：錄音跟轉出來的文字全程都在你這台電腦上，不會傳出去給任何人，包括 AI。**

轉好之後它會問你要整理成哪一種紀錄，寫進去之前還會念一次給你聽：

> 「我整理成這樣〔念出來〕，這樣可以嗎？要改哪裡跟我說。」

**你點頭它才寫進去。**

### 步驟 10：九件事的驗收（要你自己動手的那幾件別讓 AI 代答）

| # | 驗什麼 | 誰做 | 怎麼算過 |
|---|---|---|---|
| 1 | 你登入看得到 | **你** | 用你的帳號打開網址，看得到三個分頁 |
| 2 | **別的帳號被拒** | **你** | 用無痕視窗或另一個 Google 帳號打開同一個網址 → 顯示「無權檢視」 |
| 3 | 三個分頁各記一則 | **你** | 學生那頁**你勾的每一種記錄類型各記一則**，重新整理還在 |
| 4 | 三個地方對得上 | AI | 它跑一次對帳 |
| 5 | 備份真的有上去 | **你** | 打開你的雲端硬碟，**親眼看到那個壓縮檔** |
| 6 | 個資沒被帶進版本控制 | AI | 它自己檢查 |
| 7 | 健檢全綠 | AI | 見下一節 |
| 8 | 匯出打得開 | **你** | 明細頁按「匯出 ▾ → Word」，下載的檔用 Word 或 Google 文件打得開 |
| 9 | 期末素材包打得開 | 你＋AI | 跑一次，出現兩個檔，用文字編輯器打得開 |

**第 2 項沒過是最嚴重的失敗。** 看到別的帳號打得開內容，**停下所有事先修這個**，
跟 AI 說「**第 2 項沒過，別的帳號看得到內容**」。

## 2-6 ⑥ 怎麼知道裝好了：健檢

跟 AI 說：

```
幫我跑一次健檢，用白話告訴我什麼好了、什麼還沒好。
```

它會跑一支叫 `doctor.py` 的健檢程式，逐項印給你看。**符號只有四種**：

| 符號 | 顏色 | 意思 |
|---|---|---|
| `✓` | 綠 | 過了 |
| `✗` | 紅 | **必要的東西沒過**，底下那一行「→」寫著怎麼修 |
| `!` | 黃 | **選用**的東西沒裝，不算失敗，可以往下走 |
| `–` | 灰 | 跳過（用不到，例如本機模式不需要雲端那幾項） |

### 畫面上會看到

這是一台裝好的電腦（選「只放這台電腦」）真的跑出來的樣子。
注意看那個 `✗`——它把「候選路徑」都幫你找出來了：

```
健檢：/Users/你的名字/teacher-records-kit（kit 3.0.0-alpha.4，macOS）

✓ 平台 macOS（arm64）　Python 叫法：`python3`；套件管理：brew
✓ kit 版本　3.0.0-alpha.4
– 資料庫上次部署的版本（跳過：本機模式，沒有資料庫）
✓ Python 3.9 以上　目前 3.14.5
– Firebase CLI（部署安全規則與網站）（跳過：本機模式不需要）
✓ ffmpeg（錄音轉檔）　/opt/homebrew/bin/ffmpeg
✓ whisper.cpp（本機語音轉逐字稿，錄音不出本機）　/opt/homebrew/bin/whisper-cli
✓ AI 代理的 CLI（claude／codex／gemini）　找到：claude、codex、gemini
✓ Chrome／Edge（匯出 PDF 用）　/Applications/Google Chrome.app/…
✓ 語音模型 ggml-large-v3-turbo　1.6 GB
✓ 設定檔 config/kit.json　／　✓ 設定檔 config/tabs.json
✓ 資料庫模式　local——只放這台電腦，沒有 Firebase、沒有網頁
✓ owner_email 已填　t***@example.com
✓ 本機記錄檔齊全　10 個目標
✓ 學生記錄類型　導師班級學生紀錄（homeroom）、個案追蹤（通用）（case）
! 名冊 data/roster.csv（選用）　還是空的（只有表頭）
  → 用試算表打開 data/roster.csv，填「代號,姓名,類型」三欄再存成 CSV。真名只會留在你電腦上。
✓ 無頭交辦（LINE 語音／文字 → 紀錄）　沒有開（本機模式不支援）
✗ Drive 備份資料夾（desktop 模式）　（設定裡那個路徑不存在）
  → 先安裝並登入「Google 雲端硬碟」桌面程式，在雲端硬碟裡建一個資料夾，再把正確路徑填回設定。
    這台電腦上找得到的同步夾：/Users/你的名字/Library/CloudStorage/GoogleDrive-你的信箱/我的雲端硬碟

還有 1 項必要條件沒過（上面 ✗ 的部分）。照每一項的「→」修完再跑一次。
```

**還沒裝完的時候，紅色的 `✗` 會比較多**，而且每一項都寫著要跑哪一支精靈，例如：

```
✗ 設定檔 config/kit.json　還沒產生
  → 跑 `python3 scripts/setup.py` 安裝精靈；它會照你的回答產生這個檔。
✗ owner_email 已填　空的
  → 重跑 `python3 scripts/setup.py` 填你的 Google 信箱。
```

**你不用自己看懂每一行。** 把整段貼給 AI，說「**這個怎麼辦**」就好。

## 2-7 ⑦ 最後一步：加到手機主畫面

用手機打開 AI 給你的那個網址、登入，然後：

- **iPhone（Safari）**：按下面中間那個**分享鍵**（一個方框加向上箭頭）→ 往下找
  **「加入主畫面」**→ 右上角「加入」。
- **Android（Chrome）**：按右上角的**三個點**（⋮）→ **「加到主畫面」**→「安裝／新增」。

之後點桌面那個圖示，它就像一個 App 一樣打開，**上面沒有網址列**。

> **在 LINE 或 Facebook 裡點連結打不開 Google 登入**，那是 App 內建瀏覽器擋的，
> 網頁上會直接跳出提示帶你改用 Safari／Chrome。**所以請一定要加到主畫面**，
> 以後就不會再從 LINE 裡點進來了。

# 三、每天怎麼用

## 3-1 手機上：走廊上記一則

![手機上的學生記錄一覽](img/02-phone-overview.png) ![點進一位學生的樣子](img/03-phone-student-detail.png)

*左：三個分頁在最上面，下面那一排是你勾的記錄類型，再下面是全班每一位一張卡。
右：點進一位學生之後看到的他的紀錄。*

**一張卡上會看到三件事**：他的名字與代號、這個類型底下已經有幾則、最後一則是哪一天，
還有一個綠色的「**本月已記**」或紅色的「**本月未記**」。
勾上「**只看本月還沒記的**」，畫面就只留紅的那幾張——月底掃一遍很好用。

### 記一則：點進去，按「＋ 新增一則記錄」

![手機上的新增表單：日期、分類詞、這一種類型的欄位、正文](img/04-phone-add-form.png)

**畫面上會看到**（從上往下）：

1. **日期**——預設今天，可以改。
2. **分類詞那一排圓圓的按鈕**（`#課堂` `#人際` `#情緒`…）——**點一下就加上去**，
   不用自己打井號。想打自己的也可以，打在右邊那一格。
3. **這一種記錄類型的欄位**——每一格下面有一行灰字告訴你這一格要填什麼。
   有些是下拉選單，有些是可以複選的按鈕。**全部都可以留空。**
4. **正文**——最大的那一格。裡面的提示字是
   「記錄內容（客觀描述具體事件；請用代號、勿寫真名）…」。
5. **關聯**（選填）——想把這一則接到別的紀錄上再填，平常不用管。
6. 最下面兩顆：「**新增**」跟「取消」。

![分類詞：點一下就加上去，再點一下取消](img/05-tag-chips.png)

> **不小心打了真名怎麼辦：不會有事。** 網頁在存進去之前**會自己把名單上的真名換成代號**。
> 電腦那一端更嚴格，出現真名會**直接拒絕寫入**並告訴你哪裡有名字。

**改跟刪**：每一則右上角有「編輯」跟「刪除」。按下「刪除」會跳出一行提醒
「這一則會從畫面、本機與備份移除；雲端原文會保留到你自己跑 purge_deleted.py 才真的刪。確定？」，
按「**確定刪除**」才真的動，按「取消」不會有事。
**日期改不了**——一則紀錄建立之後，它屬於哪一天就鎖住了，事後誰都改不了。

### 刪除了東西去哪裡

你在網頁上刪掉的東西，**雲端資料庫裡的原文其實還在**——只是從畫面、你電腦的檔案、
下一次備份裡消失了，這樣才不會手滑真的弄丟。真的要把它從雲端永久抹掉，
只有一條路：**你自己**在電腦上開終端機跑 `python3 scripts/purge_deleted.py`。
先跑不加任何參數會只列出「已經刪了、但雲端還留著」的東西，看清楚了、
確定要清才加 `--confirm`。AI 不會、也不能幫你跑這一支——這是刻意設計成只有你自己按得下去。

### 課程記錄與業務記錄

![課程記錄分頁：一門課一張卡，主課程與科任分開列](img/08-course-tab.png)

![業務記錄分頁：你勾的那幾組，一組一張卡](img/09-business-tab.png)

記法跟學生那一頁一樣：點進一張卡 → 「＋ 新增一則記錄」。
業務那一頁的欄位跟著那一組走（例如公文那一組會有「公文字號」「期限」「辦理情形」）。

> **兩邊怎麼分工**：跟著**某一個孩子**走的事情記在學生那一頁；
> **校務層次**的事情——個案會議、通報、特教鑑定的行政流程——記在業務那一頁，
> 兩邊用「關聯」接起來。期末的素材包只取材學生那一邊。

### 整體課程紀錄

逐日紀錄回答「今天教了什麼」；**整體課程紀錄**回答「這門課整體是什麼樣子」——不分天，
一段就好，期末寫課程總結、明年再開同一門課的時候最有用。課程明細頁上方那張卡，
還沒寫過按「**＋ 寫整體紀錄**」，寫過的話是「**編輯整體紀錄**」，填完按「**儲存**」
（最多 20000 字）。一覽頁上寫過的課會多一個「**整體紀錄 ✓**」的小標籤，
Word／PDF／Markdown 匯出都會把這一段放在逐日紀錄最前面。

### 上面那一條顏色會變的列

![狀態列：灰字＝正常、紅字＝太久沒跑、琥珀色＝有東西被擋下來](img/10-statusbar.png)

這一條讀的是「你的電腦上次幫你同步、備份是什麼時候」。**只有三種顏色要認**：

| 顏色 | 你會看到 | 意思 | 怎麼辦 |
|---|---|---|---|
| **灰字** | `上次同步：今天`／`上次備份：3 天前` | 一切正常 | 不用做什麼 |
| **紅字** | `上次同步：9 天前`、`還沒有過`、`出錯：…` | 超過七天沒跑，或上一次自己出錯了 | 跟 AI 說「**幫我看同步跟備份是不是掛了**」 |
| **琥珀色**（米黃底的小方框） | `上次同步有 2 則衝突／1 則真名攔截，尚未寫回電腦` | 上次同步有東西被擋下來，那幾則還留在雲端等你處理 | 跟 AI 說「**幫我看同步擋下了什麼**」 |

**正常狀態是灰字，畫面上不會有綠色那一格。** 它每五分鐘自己更新一次。

### 沒訊號的時候

![米黃色的提示條：離線中，會在連線後送出](img/11-offline-bar.png)

教室、地下停車場沒訊號的時候，最上面會出現這一條。
**你照樣可以打開、照樣可以記**——讀過的東西留在手機裡，這時候新增的紀錄會先排隊，
**連上線自動送出**，你不用做任何事。

### 「載入更多（較舊的記錄）」

一位學生的明細頁**一次只抓最近 50 則**，更舊的按底下那顆「**載入更多（較舊的記錄）**」再翻一頁。
底下那行小字會寫「目前顯示最近 N 則」。

**這一條跟期末無關**：匯出跟期末素材包**一律含全部紀錄**，不受這個 50 則影響。

### 「示範模式」那個黃色橫幅

![示範模式：資料只存在這個瀏覽器，全是假的](img/12-demo-banner.png)

想確認網頁本身沒壞、又不想動到真資料的時候，**在網址後面加上 `?demo=1`**。
它完全不連你的資料庫，用一批假資料跑一遍，上面會出現這個黃色橫幅。
這一本書裡的每一張圖都是這個模式拍的。

### IEP 與 SOAP 的學生，明細頁上面多一張卡

![IEP 學生的明細頁上方：目標清單（新增紀錄時的「目標編號」就從這裡挑）](img/13-iep-goals.png)

- 勾了 **IEP** 的類型 → 出現「**目標清單**」，一條目標一列（領域、學年／學期目標、評量方式、
  評量標準、期程），旁邊會自己統計「已記 N 則・最近達成情形」。
- 勾了 **SOAP** 的類型 → 出現「**個案概念化**」（主訴／背景／評估假設／處遇目標／結案標準）。

這兩塊是**會被你回頭修改的底稿**，所以跟一則一則的紀錄分開存。
新增 IEP 紀錄時，「目標編號」那一格就是從這張卡上的目標裡挑；
卡上還沒有目標的話，表單會直接寫「先在上方『目標清單』加目標」。

## 3-2 電腦上：用講話記

這是這套系統最省力的入口：

```
手機錄一段話 → 丟進資料夾裡的 inbox/ → 跟 AI 說「幫我整理成學生記錄」
   → AI 轉成文字、改寫成紀錄、念給你確認 → 你點頭，它才寫進去
```

- 錄音 App 隨便哪一個都行（iPhone 內建的「語音備忘錄」最方便）。
- 傳到電腦的方法：macOS 用 AirDrop；Windows 用「手機連結」、LINE 傳給自己再下載、或 USB 線。
- **講的時候像對人講一樣把話講完整**，三件講清楚就好：**誰**（用代號）、**什麼時候**、**發生什麼**。
- 一口氣講了三個孩子也沒關係，AI 會拆成三則。
- **錄音跟文字全程在你的電腦上**，一個位元組都不外送。

> **AI 會把人名聽錯**（尤其專有名詞跟台語詞），這是正常的。它改寫的時候會順手修掉，
> 而且**寫進去之前一定會念一次給你確認**。

## 3-3 平常跟 AI 說的那幾句

「幫我同步一下」「幫我備份一次」「這個月誰還沒記？」——這幾句話背後都是一支真的程式，
AI 幫你跑。**完整的清單在第六章**，那一章可以印出來貼在電腦旁邊。

**排程**（步驟 8）掛上之後，同步跟備份每天／每週自己跑，你什麼都不用做。
但要記住一句話：**排程有可能會靜靜地壞掉**（電腦沒開機、學校電腦鎖住排程）。
**你真正該相信的是網頁上面那條列**——那個數字沒動，就是沒跑。

### 紀錄上自己多出來的維度標籤（開了「評量維度自動補標」才有）

學生卡上那五個小籤本來是網頁**打開的當下**用你打的標籤跟內文猜的，猜完不會寫回紀錄。
開了這一項之後，**每次同步完**，還沒有任何維度標籤的那幾則會交給你選的 AI 讀一次，
照實補上代表標籤——例如一則「下課幫同學撿蠟筆」會多一個 `#人際`。

- **補上的標籤跟你自己打的一模一樣**，網頁上看不出哪個是 AI 補的。**覺得不對就直接刪掉那個標**——
  那一則的內容沒改的話，它不會再被補回去。
- **你打的標籤一個都不會被動到**，只會在後面多加。你正在網頁上改的那一則會被跳過，下次同步再來。
- 送給 AI 的**只有學生代號跟正文**，名冊不會送；正文裡出現名冊上**全名**的那一則不會送。
  **只寫名字、沒寫姓的攔不到**，所以正文還是一律寫代號。
- 同步會多花一兩分鐘：每次最多讓 AI 看 60 則，舊紀錄多的時候會印「還有幾則等下次同步」，下次自己接著做。
- 同步的時候看到一行「**評量維度補標沒有跑…**」或「**這一批一個字都沒寫**」：同步本身已經好了，
  只是 AI 這一次叫不起來或回得亂七八糟，什麼都沒寫。跟 AI 說「**幫我跑一次健檢**」，看「評量維度補標的 AI 代理」那一項。

## 3-4 用 LINE 交辦（裝了才有）

對那個 LINE 官方帳號傳**文字**或**語音**，一次講一件事：

```
今天午休 S-01 主動幫忙排椅子，第一次看到他主動
S-05 第三次會談，主訴一樣是睡不著，這次願意講家裡的事
昨天第三節主課程，講到河流地形，全班都很投入
```

**你會收到兩則回覆，意思完全不一樣**：

1. 傳出去馬上收到「**收到了，電腦醒著時會處理**」——這只是雲端收到了，**還沒寫進去**。
2. 真正寫完之後才會收到第二則，寫著它記到哪裡去了，例如
   「**已記到 S-01 的導師班級學生紀錄，2026-09-12**」。**這一句才是完成。**

幾件會遇到、但其實是正常的事：

- **它不確定的時候不會猜。** 聽不清楚是哪一位學生、或分不出該記成哪一種，
  它會回「聽起來像○○，但我不確定，**沒有寫入**」。**寧可你回家自己補，也不寫一則錯的進去。**
- **電腦睡著或關機**：訊息排在雲端，一則都不會掉，也一則都不會被處理。醒來五分鐘內補完。
- **只推播一則。** LINE 免費方案每個月只有 200 則推播，所以它不會再推「開始處理了」這種進度。
- **失敗不會自動重試。** 這是刻意的：自動重試最糟的情況是同一句話被寫成三則紀錄，
  而你得自己去找出來刪掉。失敗的那一則會停在那裡等你，跟 AI 說「**幫我看 LINE 交辦有沒有卡住的**」。
- **換手機或換 LINE 帳號**：跟 AI 說一聲就好，**不用重新部署**。

# 四、期末：把一整年變成評語

## 4-1 一句話流程

```
① 素材包（程式做，一個字評語都不寫）
   → ② 貼給你的 AI，它照規則寫草稿
   → ③ 對一次稽核清單
   → ④ 你改完，就是定稿
```

**素材包只做四件確定性的事**：把紀錄依報告格式分好組、統計、**標出缺漏**、附上骨架與書寫規則。
**它不呼叫任何 AI、不寫任何一句評語**，所以同一批資料跑幾次結果都一樣。

## 4-2 網頁上那顆按鈕

![明細頁上的「產生期末素材 ▾」：下拉列出適用的報告格式](img/06-pack-menu.png)

| 在哪 | 按鈕 | 下載什麼 |
|---|---|---|
| 學生**明細頁** | **產生期末素材 ▾** | 一份檔：分好組的素材＋檔尾一段給 AI 的指令 |
| 學生**一覽頁** | **產生全班期末素材 ▾** | 一份檔、每位學生一節，檔尾附同一段指令 |

下拉裡列的是**適用於你當前那一種記錄類型**的格式，例如：

- **導師質性評量**（發展樣貌／客觀描述五維度／整體感受／導師建議）
- **科任評語四項**（關係／參與／可見的學習證據／下一步）
- **IEP／早療目標追蹤報告**（每一條目標一張表）
- **個案摘要／結案報告**
- **我們學校自己的格式**（把校方的標題貼進來就好，不用改程式）

## 4-3 把素材包交給 AI

下載的那個檔**整份貼給你的 AI**，再貼檔尾那一段指令。那段指令會要求它：

- 材料只有這份素材包，**素材包裡沒有的事一個字都不補**；
- 每一句都要指得出是哪一則、哪一天；
- 某一段沒有素材就寫「本期未蒐集到紀錄」，**不推估**。

**兩件它一定會做的事**：

1. **「整體感受」那一段留白**，只標一行「（這一段請老師自己寫）」。
   那一段在格式庫裡明寫著「AI 不代寫、不潤飾」。
2. **寫完先自己對一遍稽核清單**（每個判斷指不指得出日期與來源、有沒有出現別的學生的姓名、
   每位是不是只有一個下一步、有沒有 AI 那種對比句與定型語言），一條一條告訴你「過」或
   「哪裡不過、我怎麼改的」。

**最後一版是你的。你改完就是定稿，AI 不會回頭「順手修正」。**

## 4-4 匯出 Word 與 PDF

![明細頁上的「匯出 ▾」：Word 直接下載，PDF 會開列印版面](img/07-export-menu.png)

| 在哪 | 按鈕 | 可以選 |
|---|---|---|
| 學生明細頁 | **匯出 ▾** | Word 與 PDF 各兩項：「只匯出目前這一種記錄類型」或「這位學生全部類型」 |
| 課程／業務／班級整體觀察明細頁 | **匯出 ▾** | 匯出 Word、匯出 PDF |
| 學生一覽頁 | **匯出所有學生 ▾** | 勾要哪幾種類型、填日期範圍（留空＝全部）、可勾「含班級整體觀察」 |

- **Word 是直接下載一個檔**，Word、Google 文件、Pages 都打得開。
- **PDF 是開一個乾淨的列印版面**，你在列印視窗裡選「**儲存為 PDF**」。手機的分享選單裡一樣有。

**要整包帶走**（換系統、留存、交接）也可以：跟 AI 說「**幫我把全部紀錄匯出成一個檔**」。
這件事本身就是一個承諾：**你的資料隨時可以整包帶走，不會被鎖在這套東西裡。**

## 4-5 匯出給 AI（Markdown）

明細頁「**匯出 ▾**」、學生一覽的「**匯出所有學生 ▾**」面板都多一項
**「Markdown（.md，給 AI）」**；課程一覽頁另外有一顆「**全部課程匯出 .md**」。
格式跟你電腦上的紀錄檔一樣（好讀、好貼），正文一律代號，**真名只在檔案最後面的
「附錄：代號對照」**，開頭還會標一行「唯讀副本，不要複製回 data/」提醒你這只是快照。
要把一整年紀錄整份貼給 AI 寫評語、寫課程總結的時候，用這個。

# 五、你的東西放在哪裡、什麼絕對不能給別人

## 5-1 東西放在哪裡

| 東西 | 放在哪 | 誰看得到 |
|---|---|---|
| 你的紀錄（文字） | 你電腦上的 `data/` 資料夾 ＋（雲端模式）你自己的資料庫 | 只有你 |
| **學生真名** | 你電腦上 `data/roster.csv` 這**一個**檔 | 只有你。**不上傳、不進版本控制** |
| 錄音與逐字稿 | 你電腦上的 `inbox/` | 只有你。**永不外送** |
| 備份壓縮檔 | 你電腦上的 `backups/` ＋ 你自己的雲端硬碟 | 只有你 |
| 匯出的 Word／PDF、期末素材包 | 你電腦上的 `exports/` | 只有你（**這些檔含真名**） |

**真正擋住別人的是一條伺服器規則**：只有你那一個 Google 帳號讀得到、寫得進去。
就算有人拿到你的網址、看了網頁原始碼，伺服器一樣不會回傳任何一個字。

**代號不等於匿名。** 代號的用處是「這些文字可以安心交給 AI 讀、可以匯出、可以備份」；
你自己的名單一對照就知道是誰。所以**名單檔本身不要外流**。

## 5-2 絕對不要貼給任何人的東西

這一節請認真看。

| 絕對不要貼 | 為什麼 |
|---|---|
| **應用程式密碼／App Password** | 拿到的人可以用你的身分寄你的信 |
| **任何檔名裡有 `key` 的檔案內容**、`.env` | 等於整個專案的鑰匙 |
| **你的 Google 帳號密碼** | 任何人任何理由都不會需要它，**包括 AI** |
| **LINE 的兩串金鑰**（開了 LINE 交辦才有） | 拿到的人可以冒充你的 LINE 官方帳號 |
| **`data/roster.csv`** | 整套系統裡唯一有真名的檔 |
| `exports/` 與 `backups/` 底下的檔 | 匯出檔與備份**含真名** |

**「絕對不要」的範圍是任何人**：同事、技術論壇、賣你這套東西的人、你在別的地方開的 AI 對話視窗。
**唯一的例外**是你電腦上正在幫你安裝的那個 AI——即使是它，你也**不需要主動把密碼貼給它**。

**如果有東西（不管是誰）叫你「把密碼貼過來」，先停下來，去問作者。**

### 可以貼、不用緊張的

- **那六個設定值**（`apiKey`、`projectId` 那些）。名字裡有 key，但它們本來就會出現在
  網頁原始碼裡，任何人打開你的網站都看得到。保護你資料的不是它們。
- **錯誤訊息**。全部貼給 AI，**越完整越好**。

# 六、常用的話怎麼跟 AI 說

**這一頁可以印出來貼在電腦旁邊。** 左邊是你可以直接說的話，右邊是它實際會幫你做的事。

### 記一則

| 你說 | 它做什麼 |
|---|---|
| `幫我記一則：S-03 今天數學課主動舉手三次，最後一題還上台講解。` | 走系統的寫入通道寫進去，順便幫你檢查有沒有寫到真名 |
| `inbox 裡有一個錄音，幫我整理成課程記錄。` | 在你的電腦上轉成文字 → 改寫 → 念給你確認 → 你點頭才寫進去 |
| `這段錄音是第 3 次會談，整理成 SOAP。` | 拆成 S／O／A／P 四段，補會談次數、形式、風險評估、下次時間 |
| `幫我把 S-02 的 IEP 目標記進去。` | 對照他卡片上的目標分段，一條目標一則 |

### 每天／每週

| 你說 | 它做什麼 |
|---|---|
| `幫我同步一下。` | 電腦與網頁兩邊對起來；兩邊都改過的**不覆蓋任何一邊**，印出來讓你決定 |
| `這次同步先不要補維度標籤。` | 照樣同步，但這一次跳過「評量維度自動補標」那一段（開了這一項才有） |
| `幫我備份一次。` | 打包成壓縮檔放進你自己的雲端硬碟，比對過檢查碼才算完成 |
| `這個月誰還沒記？` | 列出本月還沒有紀錄的學生（網頁上勾「只看本月還沒記的」是同一件事） |
| `幫我跑一次健檢，用白話告訴我結果。` | 逐項檢查，沒過的每一項都會寫「→ 怎麼修」 |
| `幫我看同步跟備份是不是掛了。` | 看排程掛了沒、上次跑是什麼時候、有沒有出錯 |
| `幫我看同步擋下了什麼。` | 把衝突與真名攔截那幾則逐則印出來，一則一則陪你處理 |
| `幫我看三個地方對不對得上。` | 比對「你的電腦、網站、最近一次備份」三處，對不上就列出差在哪 |
| `幫我看 LINE 交辦有沒有卡住的。` | 待處理、處理中、完成、失敗各幾則；失敗的列出原因 |

### 期末

| 你說 | 它做什麼 |
|---|---|
| `幫我出 S-03 的期末素材。` | 依報告格式分好組，另外出一份寫草稿的指令；**缺漏的分組會照實列出來** |
| `幫我出全班的期末素材。` | 每位學生一份，另外出一份總表，誰還缺什麼一眼看得出來 |
| `幫我匯出全班的 Word。` | 一份文件、每位學生一節，可以把班級整體觀察放在最前面 |
| `幫我把 S-03 的記錄匯出成 Word 跟 PDF。` | 一位學生、全部類型，卡片上的 IEP 目標與個案概念化排在紀錄前面 |
| `幫我把全部紀錄匯出成一個檔。` | 整包帶走（可以依標籤分組，也可以每個對象一個資料夾） |

### 改設定、加東西

| 你說 | 它做什麼 |
|---|---|
| `我還要一種學生記錄類型，是記○○的。`／`我還要一組業務記錄，是關於○○的。` | 問清楚（叫什麼、要填哪些欄位、常用分類詞）→ 改設定 → 重新產生 → 重新部署 |
| `我在網頁上加了一種○○，幫我寫進設定。` | 網頁上臨時加的**只有網頁看得到**，這一句才會讓電腦那一端跟上 |
| `把 S-07 列入個案追蹤。` | 改名冊第三欄（網頁上按「＋ 列入學生」是同一件事） |
| `我想改成雲端。` | 改設定、問那幾個值、部署、上線；**已經記的東西一則都不會動** |
| `幫我寄給 S-01 的家長，先給我看稿。` | 先產生草稿給你看。**你沒點頭之前，它一封都不會寄出去** |

### 出問題

```
（整段貼上錯誤訊息）這個怎麼辦？
你剛剛那步好像沒成功，可以檢查一下嗎？
等一下，我覺得這樣不對，先停下來。
我們現在做到第幾步了？
讀 AGENTS.md，接著上次的進度繼續裝。
```

# 七、卡住的時候

## 7-1 只要記住一件事

**畫面上跳出一堆看不懂的英文 → 整段複製，貼給 AI，加一句「這個怎麼辦」。**

不要自己 google、不要慌、不要重開機。那些訊息 AI 讀得懂。
怎麼複製：在終端機裡用滑鼠選取那段文字 → `⌘ + C`（Windows：`Ctrl + C`）→ 到 AI 的輸入框貼上。

## 7-2 最常見的十件事

| 症狀 | 多半是 | 怎麼辦 |
|---|---|---|
| 剛裝完，健檢還是說「找不到」 | 新裝的程式要新視窗才叫得到 | **關掉終端機、開一個新的**，再跑一次健檢 |
| **iPhone 上登入後一直跳回未登入** | 一個設定值填成了另一個網域 | 跟 AI 說「**iPhone 上登不進去**」，它知道要改哪裡（這是已知的坑，有標準修法） |
| **別的帳號打得開、看得到內容** | 規定沒送上去成功，或裡面的信箱打錯 | **停下所有事先修這個。** 跟 AI 說「**別的帳號看得到內容**」 |
| 網頁說「你的安全規則還是舊版」／刪除鍵按不動 | 更新程式之後沒有重新把規定送上去 | 跟 AI 說「**幫我重新部署規則**」 |
| 網頁停在「還沒有設定檔」／頁尾寫「版本未知」 | 設定檔沒被送上去 | 跟 AI 說「**網頁說還沒有設定檔**」 |
| 上面那條列變**紅字** | 排程沒跑成功（電腦沒開機、學校電腦鎖住排程） | 跟 AI 說「**幫我看同步跟備份是不是掛了**」 |
| 上面那條列出現**琥珀色** | 上次同步有東西被擋下來 | 跟 AI 說「**幫我看同步擋下了什麼**」 |
| 轉錄卡住／語音模型下載失敗 | 網路 | 跟 AI 說「**重跑一次轉錄**」（已經轉過的不會重轉） |
| 匯出 PDF 失敗 | 電腦上找不到 Chrome | **不算失敗**：它會留下一個排版好的網頁檔，用瀏覽器開 → 列印 → 儲存為 PDF |
| 健檢說「Drive 備份資料夾」是 `✗` | 桌面程式沒登入，或資料夾名字打錯 | **中文的全形空格是最常見的兇手。** 照健檢列出來的候選路徑對一次 |

## 7-3 LINE 交辦的三件事

| 症狀 | 多半是 | 怎麼辦 |
|---|---|---|
| **傳出去完全沒有任何回應** | 雲端那支程式沒部署好、或開關沒打開 | 跟 AI 說「**LINE 傳出去完全沒反應**」 |
| **一直收到「配對碼：Uxxxx…」** | 配對碼還沒送上雲端 | 把那一串貼給 AI，說「**這是我的配對碼**」 |
| **收到「收到了」，第二則永遠不來** | 電腦沒醒著、排程沒跑，或金鑰排程讀不到 | 跟 AI 說「**收到了但沒有第二則回報**」 |

> LINE 主控台那顆 **Verify 按鈕回 `401` 是對的**（它送的是空簽章，本來就該被擋）。
> 只有 404、500 才是真的有問題。

## 7-4 中途要休息、或明天再接

可以。進度它自己記著。明天打開終端機、`cd` 進那個資料夾、把 AI 叫起來，然後說：

```
讀 AGENTS.md，接著上次的進度繼續裝。
```

**它不會把你答過的題目再問一遍。**

# 八、Windows 的人：幾個地方不一樣

| 這本書裡寫的 | Windows 上換成 |
|---|---|
| 開終端機 | 按 **Windows 鍵** → 打 `terminal` 或 `PowerShell` → Enter。**不要用 cmd、不要用 WSL** |
| 貼上文字 | `Ctrl + V`（複製是 `Ctrl + C`） |
| `bash setup/bootstrap.sh` | 對 `setup\bootstrap.cmd` **按兩下** |
| 跳出來要你同意的視窗 | 「使用者帳戶控制」→ 按「是」 |
| 資料夾放哪 | `C:\Users\你的名字\teacher-records-kit`。**不要放 OneDrive 底下** |
| 雲端硬碟資料夾 | 通常在 `G:\我的雲端硬碟\…`（磁碟機代號因人而異） |
| 排程 | 「工作排程器」裡的三個工作。跑的時候會**閃一下黑色視窗，正常** |

**WSL 直接不支援**，腳本會拒跑。備份夾與排程都在 Windows 那一邊，WSL 看不到，會靜靜地失效。

> **老實說**：Windows 上這一套的每一個環節都有自動測試看著，
> 但**還沒有真人老師在 Windows 上從頭裝過一次**。你遇到怪狀況，先當是我們的問題，
> 把畫面跟訊息整段貼給 AI，也回報給作者。

# 九、名詞小字典（看到不懂的字回來查）

| 你會看到的字 | 白話 |
|---|---|
| **終端機／Terminal／PowerShell** | 黑底白字那個視窗。AI 住在裡面 |
| **bootstrap** | 「打地基」的那支腳本，把該裝的東西一次裝齊 |
| **健檢／doctor** | 逐項檢查「什麼好了、什麼沒好」的那支程式 |
| **安裝精靈／setup** | 問你問題、把你的答案寫成設定的那支程式 |
| **同步** | 把你電腦上的紀錄跟網頁上的對起來 |
| **部署** | 把東西（網頁、規定）送上網路那個動作 |
| **安全規則／規定** | 伺服器上那條「只有你那個帳號讀得到」的規矩。**真正保護你資料的東西** |
| **記錄類型** | 學生記錄底下分開的幾本簿子（質性評量／導師／科任／個案／IEP／SOAP） |
| **代號** | `S-01` 這種編號。紀錄正文一律寫代號，真名只在你電腦上的名單檔 |
| **關聯** | 把一則紀錄接到另一則上（例如個案會議接回那位學生那一天的紀錄） |
| **素材包** | 期末把整年紀錄分好組的那一份檔。**它不寫評語** |
| **衝突** | 同一則在網頁跟電腦上都改過。系統**不覆蓋任何一邊**，等你決定 |
| **真名攔截** | 系統在紀錄裡發現名單上的真名，把那一次寫入擋下來 |
| **示範模式** | 網址加 `?demo=1`，用假資料跑一遍，完全不連你的資料庫 |

# 十、最後三句話

1. **沒有東西是系統替你決定的。** 你勾了什麼才有什麼，一個都不勾也是合法的結果。
   覺得哪一組不對、少了什麼，直接跟 AI 說，改設定就好。
2. **不確定就問 AI，問錯不會壞。** 真正會出事的動作（部署、寄信、刪除）它都會先問過你。
3. **你改完的那一版就是定稿。** AI 不會回頭動你的字。

> **這一版的老實話**：`3.0.0-alpha.4`。
> 雲端模式的文字路徑（網頁、同步、備份、匯出、期末素材包）是驗得最紮實的一條；
> 只放這台電腦次之；**LINE 交辦請當成試用版**——它的每一行程式都有測試看著，
> 但它從來沒有真的在網際網路上跑過一次。開了之後第一週，請自己對一下它寫進去的紀錄。
>
> 想知道更細的（每一支程式、每一個旗標、每一種錯誤的退出碼）→ `docs/PRODUCT-MANUAL.md`。
